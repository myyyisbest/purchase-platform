=====================================
采购分析平台 — 数据表模板说明
=====================================

本目录包含系统所需的全部数据表CSV模板，每个文件对应一张数据库表。
你可以用 pandas 从 SAP 导出数据清洗后，按以下模板格式生成 CSV 文件，
然后通过系统的"数据导入"功能上传，或直接给我让我导入。

🔑 关键注意事项
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 采购记录表 — 列名必须严格匹配
   系统按中文列名读取，列名改了会导入失败。
   最小必填列: 公司, 日期, 年度, 物料代码, 供应商名称, 金额(订单货币), 订单货币

2. 编码字段 — 数字型编码要保持原样
   公司代码(如1000)、物料代码(如10005587)、供应商编号(如SUP001)
   这些是字符串，pandas读取后不要变成浮点数。
   清洗时建议: df['物料代码'] = df['物料代码'].apply(lambda x: str(int(x)) if pd.notna(x) and isinstance(x, float) and x == int(x) else str(x))

3. 日期格式 — YYYY-MM-DD
   pandas.to_datetime(col).dt.strftime('%Y-%m-%d') 即可

4. 金额计算逻辑
   系统会自动计算: cny_amount = 金额(订单货币) × 汇率(订单货币→CNY)
   所以只要保证 "订单货币" 和 "金额(订单货币)" 正确即可
   汇率在汇率表中维护，不需要在采购记录里手动填

5. 关联方过滤
   供应商类别='关联方' 的行会在导入时自动排除（不计入分析）

6. 组织层级关系
   集团(Group) → 事业部(BusinessUnit) → 板块(BusinessSector) → 公司(Company)
   公司表CSV中可以同时包含上级板块/事业部/集团的编码和名称，
   导入时会自动创建和关联。

🐼 pandas 清洗示例
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

import pandas as pd

# 读取 SAP 导出的原始 Excel
df = pd.read_excel('SAP采购台账_2025.xlsx')

# 1. 清洗数字型字符串编码
def clean_code(val):
    if pd.isna(val): return ''
    if isinstance(val, float) and val == int(val):
        return str(int(val))
    return str(val).strip()

df['公司'] = df['公司'].apply(clean_code)
df['物料代码'] = df['物料代码'].apply(clean_code)
df['供应商编号'] = df['供应商编号'].apply(clean_code)

# 2. 清洗日期
df['日期'] = pd.to_datetime(df['日期']).dt.strftime('%Y-%m-%d')

# 3. 填充空值
df['订单货币'] = df['订单货币'].fillna('CNY')
df['供应商类别'] = df['供应商类别'].fillna('')

# 4. 数值列填0
for col in ['采购数量','采购单价','采购金额','金额(订单货币)','单价(订单货币)']:
    if col in df.columns:
        df[col] = pd.to_numeric(df[col], errors='coerce').fillna(0)

# 5. 输出为系统可识别的CSV
output_cols = ['公司','公司名称','年度','日期','供应商编号','供应商名称','供应商类别',
               '物料代码','物料名称','规格型号','物料类别','记账本位币',
               '采购单位','采购数量','采购单价','采购金额',
               '订单货币','单价(订单货币)','金额(订单货币)',
               '采购用途','采购订单','物料凭证','行项目',
               '会计凭证号码','移动类型','移动类型描述','冲销标识',
               '行项目类别','标识：基于收货的发票验证','行项目文本']
# 只保留存在的列
existing_cols = [c for c in output_cols if c in df.columns]
df[existing_cols].to_csv('采购记录表_清洗后.csv', index=False, encoding='utf-8-sig')

# ⚠️ encoding='utf-8-sig' 确保Excel也能正确打开

❓ 常见问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: SAP 原始台账的列名跟模板不一样怎么办？
A: 用 pandas rename 映射即可，关键是保证输出CSV的列名跟模板一致。

Q: 新增了一家公司怎么处理？
A: 在"01_组织架构_公司表.csv"加一行，确保 company_code 唯一。
   采购记录中引用的公司代码必须在公司表中存在（不影响导入，但影响组织筛选）。

Q: 汇率缺失会怎样？
A: 系统会尝试用"采购金额"列兜底（假设本位币=CNY），但如果本位币不是CNY则会为0。
   建议每年初更新一次汇率表。

Q: 能不能分批导入（如一个月导一次）？
A: 可以。系统按"物料凭证+行项目"去重，重复导入不会重复入库。

Q: 物料大类维护表必须吗？
A: 不是必须的。没有维护的物料在Dashboard的"物料大类分布"图中会显示为"未维护"。
   但建议逐步维护，让分布图更有意义。
